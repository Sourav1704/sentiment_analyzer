# 🤖 AI Sentiment Analysis Web App

A full-stack AI-powered sentiment analysis web application built using BERT, PyTorch, Flask, HTML, CSS, and JavaScript.

The application analyzes user text in real-time and predicts whether the sentiment is **Positive** or **Negative** using a BERT-based Natural Language Processing (NLP) model.

---

# 🚀 Features

- Real-time sentiment prediction
- BERT-based NLP model
- Flask backend API
- Interactive chatbot-style frontend
- Confidence percentage visualization
- Positive and negative sentiment detection
- Full-stack AI integration
